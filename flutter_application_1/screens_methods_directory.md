# Справочник окон и методов приложения (Flutter Application)

В данном документе собрано описание всех окон (экранов) приложения, расположенных в директории `lib/screens/`, а также ключевых методов, которые в них используются, и их краткое назначение.

---

## 1. Окно авторизации / входа (`login_screen.dart`)
*Экран входа пользователя в систему по email и паролю.*

| Метод | Описание |
| :--- | :--- |
| `_login()` | Выполняет валидацию полей ввода, авторизует пользователя через `AuthProvider` (Supabase Auth) и при успешном входе перенаправляет на главный экран. |
| `_buildHeroBanner()` | Строит верхнюю графическую и текстовую панель с приветственным баннером. |

---

## 2. Окно регистрации (`register_screen.dart`)
*Экран создания новой учетной записи.*

| Метод | Описание |
| :--- | :--- |
| `_register()` | Регистрирует нового пользователя в системе по email и паролю, проверяет согласие с правилами сервиса и обрабатывает ошибки регистрации. |
| `_openTermsPdf()` | Открывает документ пользовательского соглашения в формате PDF. |
| `_buildAgreementCheckbox()` | Строит интерактивный чекбокс для подтверждения согласия с условиями использования. |
| `_buildHeroBanner()` | *(Общий метод)* Строит верхнюю графическую и текстовую панель с приветственным баннером. |

---

## 3. Главный экран с навигацией (`main_screen.dart`)
*Экран, управляющий переключением основных вкладок приложения (Курсы, Чат, ИИ-Помощник, Профиль) через `BottomNavigationBar`.*

---

## 4. Окно приветствия / онбординга (`onboarding_screen.dart`)
*Экран с презентацией возможностей приложения для новых пользователей.*

| Метод | Описание |
| :--- | :--- |
| `_buildDot({required int index})` | Строит индикаторы (точки) текущей страницы для слайдера презентации (`PageView`). |

---

## 5. Окно списка курсов (`courses_screen.dart`)
*Основной экран со списком доступных обучающих курсов, возможностью фильтрации и поиска.*

| Метод | Описание |
| :--- | :--- |
| `_setupStreams()` | Настраивает потоки данных (Streams) для получения списка курсов из базы данных Supabase в реальном времени. |
| `_applyFilter([String? categoryLabel])` | Фильтрует список курсов по выбранной категории или поисковому запросу. |
| `_formatDate(DateTime? date)` | Форматирует дату публикации курса для корректного отображения пользователю. |
| `_showFilterBottomSheet()` | Отображает нижнюю шторку (bottom sheet) для выбора параметров сортировки и фильтрации курсов. |
| `_buildPathBanner()` | Строит декоративный верхний баннер с приветствием пользователя. |
| `_buildCategoryChip(String label, IconData icon)` | Строит интерактивный чип категории курса для быстрой фильтрации. |
| `_buildCourseIcon(String? icon)` | Возвращает соответствующую иконку для курса на основе строкового идентификатора из базы данных. |
| `_buildCourseCard(CourseModel course)` | Строит карточку отдельного курса с отображением прогресса прохождения, автора, рейтинга и цены. |

---

## 6. Окно профиля курса (`course_profile_screen.dart`)
*Экран детальной информации о конкретном курсе, содержащий описание, отзывы и список учебных модулей.*

| Метод | Описание |
| :--- | :--- |
| `_checkEnrollment()` | Проверяет, записан ли текущий пользователь на данный курс (куплен ли он или начат прохождение). |
| `_toggleFavourite()` | Добавляет курс в список избранных или удаляет его оттуда с сохранением состояния в базе данных. |
| `_checkAndGenerateCertificate(UserModel user)` | Проверяет прогресс пользователя по курсу и автоматически генерирует PDF-сертификат, если курс успешно завершен. |
| `_loadModules()` | Загружает модули и подмодули курса из базы данных Supabase. |
| `_handlePurchase()` | Открывает диалоговое окно оплаты курса и проводит транзакцию покупки. |
| `_continueLearning()` | Перенаправляет пользователя на его текущий активный/непройденный подмодуль для продолжения обучения. |
| `_buildCourseBanner()` | Строит верхний баннер с изображением курса, названием, кнопкой «Назад» и кнопкой «Избранное». |
| `_buildTabSelector()` | Переключатель вкладок между разделами «О курсе», «Модули» и «Отзывы». |
| `_buildModulesList()` | Отображает иерархический список модулей курса и подмодулей с индикацией прогресса их прохождения. |

---

## 8. Окно теоретического материала подмодуля (`submodule_content_screen.dart`)
*Экран изучения теории подмодуля (поддерживает текст в формате Markdown и воспроизведение Видео).*

| Метод | Описание |
| :--- | :--- |
| `_initializeVideo()` | Инициализирует видеоплеер, если теоретический материал представлен в видеоформате. |
| `_fetchMarkdown()` | Загружает текстовый материал подмодуля в формате Markdown по URL из базы данных. |
| `_saveProgressAuto()` | Автоматически сохраняет прогресс прохождения текущего подмодуля пользователем. |
| `_completeCourse()` | Отмечает подмодуль завершенным и проверяет возможность генерации сертификата. |
| `_goToNextSubmodule()` | Выполняет переход к следующему подмодулю курса, учитывая наличие тестов или практических заданий. |
| `_buildVideoUI()` | Отображает интерфейс видеоплеера с кнопками управления. |
| `_buildMarkdownUI()` | Отображает текстовый контент подмодуля с поддержкой форматирования Markdown. |
| `_buildTopicItem(IconData icon, String text)` | Строит элемент списка тем или ключевых моментов подмодуля. |
| `_buildNextLessonPreview()` | Строит превью следующего урока/подмодуля в нижней части экрана. |
| `_buildBottomNavigation()` | Строит нижнюю панель навигации с кнопками «Назад» и «Далее». |

## 9. Окно тестирования (`tests_screen.dart`)
*Экран с вопросами и тестами для проверки знаний по подмодулю.*

| Метод | Описание |
| :--- | :--- |
| `_submitAnswer()` | Фиксирует выбранный пользователем ответ на текущий вопрос, проверяет его правильность и начисляет баллы. |
| `_nextTest()` | Переключает на следующий вопрос теста. |
| `_finishTest()` | Завершает тестирование, сохраняет результаты в базу данных и обновляет статус прохождения подмодуля. |
| `_goToNextItem()` | Переводит пользователя к следующему элементу курса (практическому заданию или к следующему подмодулю). |
| `_buildOption(String option)` | Строит вариант ответа в виде интерактивной кнопки с изменением цвета при выборе/проверке. |
| `_buildFeedbackArea(TestModel currentTest)` | Строит область обратной связи с подробным объяснением правильного/неправильного ответа. |
| `_buildMainButton()` | Строит главную кнопку действия («Проверить», «Далее», «Завершить»). |
| `_buildResultsScreen()` | Отображает финальный экран результатов тестирования со статистикой правильных ответов и набранными баллами. |
| `_buildDecorativeSphere(Color color, double size)` | Вспомогательный метод для построения фонового декоративного элемента (сферы). |
| `_buildEmptyState(String message)` | Строит заглушку при отсутствии доступных тестов. |

## 10. Окно практического задания / написания кода (`practical_task_screen.dart`)
*Интерактивное окно с компилятором/редактором кода для выполнения практического задания.*

| Метод | Описание |
| :--- | :--- |
| `_runTests()` | Запускает автоматическое тестирование написанного пользователем кода на основе тестовых сценариев задания. |
| `_saveTaskResult()` | Сохраняет результат выполнения задания в базу данных и отмечает подмодуль как пройденный. |
| `_goToNextItem()` | *(Аналог из tests_screen)* Переводит пользователя к следующему элементу курса. |
| `_buildTaskDescription(bool isDark)` | Строит блок с описанием и условиями практического задания. |
| `_buildLanguageChip()` | Строит индикатор языка программирования, используемого в задании. |
| `_buildCodeEditor(bool isDark)` | Строит поле ввода/редактор кода с подсветкой синтаксиса. |
| `_buildTestResults(bool isDark)` | Отображает блок с детальными результатами прохождения тестов. |
| `_buildTestResultItem(...)` | Строит элемент отображения конкретного тест-кейса (пройден / не пройден). |
| `_buildResultDetail(...)` | Строит строку с деталями ошибки выполнения (вывод, ожидалось, получено). |
| `_buildActionButtons(bool isDark)` | Строит кнопки управления («Проверить код», «Далее»). |
| `_buildDecorativeSphere(...)` | *(Аналог из tests_screen)* Строит фоновую декоративную сферу. |

## 16. Окно личного чата (`user_chat_screen.dart`)
*Экран индивидуального чата со студентом, автором или поддержкой.*

| Метод | Описание |
| :--- | :--- |
| `_loadMessages()` | Загружает историю сообщений для данного диалога из базы данных. |
| `_subscribeToRealtimeMessages()` | Настраивает подписку на обновления таблицы сообщений в реальном времени через Supabase Realtime API для мгновенного отображения новых сообщений. |
| `_sendMessage()` | Отправляет новое текстовое сообщение в чат и записывает его в базу данных. |
| `_scrollToBottom()` | Автоматически прокручивает список сообщений к самому низу при открытии чата или получении новых сообщений. |
| `_buildMessageBubble(...)` | Строит пузырь сообщения с аватаром отправителя, текстом и временем. |
| `_buildMessageInput()` | Строит панель ввода сообщения с текстовым полем и кнопкой отправки. |
